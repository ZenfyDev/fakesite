Meet the main components

A computer has several parts that work together to run programs, show graphics, and store information.

🧠

CPU

The central processing unit follows instructions and performs calculations. You can think of it as the computer's main processor.

⚡

RAM

Random access memory temporarily holds information that active programs need. Its contents are usually lost when the power turns off.

💾

Storage

An SSD or hard drive keeps files, apps, and the operating system even after you shut down your computer.

🎮

GPU

The graphics processing unit helps draw images and video, and speeds up certain kinds of parallel calculations.

🔌

Motherboard

The main circuit board connects the CPU, memory, storage, and other components so they can communicate.

🔢

Binary

Computers represent information using bits: zeros and ones. Groups of bits can represent numbers, letters, pictures, and more.

Fun fact: A byte usually contains 8 bits. That's why the site's called ByteSize!
